# 二軸 SG90 雲台接線與操作

## 接線

| 功能 | Nano 腳位 |
| --- | --- |
| 水平 SG90 訊號線 | D9 |
| 垂直 SG90 訊號線 | D10 |
| 兩顆 SG90 GND | Nano GND 與外部伺服電源 GND 共地 |

兩顆 SG90 建議使用獨立且穩定的 5V 電源供電。不要長時間由 Nano 的
5V 腳同時供應兩顆伺服；瞬間電流可能讓 Nano 重開機。

## 序列監控

設定為 115200 baud。

| 指令 | 功能 |
| --- | --- |
| `P120` | 水平轉至 120° |
| `T45` | 垂直轉至 45° |
| `120,45` | 水平轉至 120°，再垂直轉至 45° |
| `C` | 兩軸回 90° 中央位置 |
| `?` | 顯示指令說明 |
