# 下午雲台、座標校正與目標搜尋測試

## 範圍與保留事項

- Nano #1 目前的 L298N 測試韌體維持不變。
- 雙軸 SG90 雲台使用另一片 Nano，採用已驗證的序列控制協定：
  `pan,tilt`，例如 `90,90`，115200 baud。
- 雲台訊號腳位：Pan = D9、Tilt = D10；兩顆伺服使用外部穩定 5V，並與 Nano 共地。

## 下午成功標準

1. 攝影機可靠地找出目標。
2. 雲台可由電腦以 `pan,tilt` 指令安全、可重複地控制。
3. 完成螢幕／投影平面四角的座標到雲台角度映射。
4. 畫面中的目標座標可換算成雲台角度，讓雷射點落在目標附近。
5. 最後才開啟合規低功率雷射作最終驗證。

## 先釐清 demo 現況

`laser_pointer_demo/vision_pointer.py` 實際偵測的是**藍色**目標；綠色是畫面上
繪製的中心準星。測試時使用藍色、和紅色雷射點明顯不同的目標標記。

現有 demo 採用閉迴路：根據藍色目標相對於攝影機中心的誤差，逐次調整雲台角度。
它尚未包含「畫面座標直接映射到雷射落點角度」的校正；四角校正將補上這一層。

## 測試順序

### 1. 機構與手動序列控制

1. 雷射保持關閉。
2. 雲台上電後，傳送 `90,90`，確認兩軸中央位置。
3. 逐一以小幅度測試 `P100`／`T100` 或 `100,100`。
4. 記錄不撞到機構極限的 `PAN_MIN`、`PAN_MAX`、`TILT_MIN`、`TILT_MAX`。
5. 固定攝影機與雷射的相對位置；校正後不可再移動任一者。

### 2. 四角角度校正

在雷射投射的平面上定義座標：左上 `(0,0)`、右上 `(1,0)`、左下 `(0,1)`、右下 `(1,1)`。
以手動序列指令將雷射依序對準四角，記錄每一角的雲台角度：

| 平面位置 | Pan | Tilt |
| --- | ---: | ---: |
| 左上 `P00,T00` |  |  |
| 右上 `P10,T10` |  |  |
| 左下 `P01,T01` |  |  |
| 右下 `P11,T11` |  |  |

另量測中心與四條邊的中點。這些點用來驗證四角映射，不能拿來調整四角數據。

### 3. 四角雙線性映射

目標在畫面／平面中的正規化位置為 `u`（左 0、右 1）與 `v`（上 0、下 1）。

```text
pan  = P00(1-u)(1-v) + P10u(1-v) + P01(1-u)v + P11uv
tilt = T00(1-u)(1-v) + T10u(1-v) + T01(1-u)v + T11uv
```

這是平面四角校正的 MVP。若中心或邊緣誤差很大，表示攝影機與雷射存在明顯視差／
透視，下一步改用 3×3 或更多校正點與 homography。

### 4. 視覺目標搜尋

1. 先關閉雷射，確認 OpenCV 只偵測藍色目標。
2. 確認目標移動時，程式取得正確 `(x,y)` 畫面座標。
3. 將 `(x,y)` 正規化為 `u=x/(width-1)`、`v=y/(height-1)`。
4. 將 `(u,v)` 經四角映射後，以 `pan,tilt` 發送至 Nano。
5. 再開啟低功率雷射，檢查雷射點是否落在目標附近。

## 安全

- 所有機構和視覺追蹤都先在雷射關閉時驗證。
- 僅使用合規低功率雷射；避開人眼、反光面與公共區域。
